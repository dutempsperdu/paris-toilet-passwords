# 🚽 Paris Toilet Passwords

Community-driven access codes for toilets in Paris fast-food restaurants.

## ✨ Features

- 🎯 **3 nearest locations** - Geographically closest to you
- 🔐 **Real-time codes** - Updated by the community
- 🗺️ **Interactive map** - See all locations at a glance
- 📊 **Dashboard** - Stats and MBTI insights
- 🌍 **Multi-language** - EN / FR / 中文 / 한국어

## 🛠️ Tech Stack

- React 19 + Vite
- TailwindCSS
- Supabase
- Leaflet + OpenStreetMap
- i18next

## 🚀 Quick Start

```bash
git clone https://github.com/dutempsperdu/paris-toilet-passwords.git
npm install
npm run dev
